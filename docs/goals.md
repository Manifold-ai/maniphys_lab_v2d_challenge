# Goals

## 北极星

在 V2D Challenge **Track 2: Robotic Grounding** 的三个输入档位上各自取得尽可能高的
排名，并用同一套管线回答赛题本身的问题：**下游策略能容忍多大的重建误差。**

赛事把「人类视频 → 机器人数据」这条链分成三段来测，Track 2 测的是中间那段：给定
4D 人-物交互数据，能不能在固定本体（G1 + Dex3）与固定仿真器上训出跟得上物体轨迹的
策略。三个档位代表上游重建质量由高到低：

| 档位 | 输入 | 我们要做什么 |
|---|---|---|
| Tier 1 | 多视角捕获的干净轨迹，上游重建的上界 | 重定向 + 训练；这一档衡量的是纯下游能力 |
| Tier 2 | 按 Track 1 误差分布采样的合成扰动（抖动、丢帧、接触错误） | 先从带噪轨迹恢复更好的估计，再走同一条下游 |
| Tier 3 | 现成方法的重建（参考方案 CARI4D） | 从 exo 视频自行重建或改进重建，再走同一条下游 |

## 怎么衡量

官方指标是物体跟踪精度的四项：**AUC、SP-SR、MP-SR、MPPE**，定义见 CHORD 论文，
三档分开计分、分数不可跨档比较。**四项的精确定义本仓尚未核对**，核对前不在任何文档里
复述它们的含义；核对后写进 `evaluate` 契约，并由本地复算与官方脚本对账。

本地需要一个与榜单一致的离线分数，原因是提交次数有上限（每周 5 次，冻结前最后三天
不限），榜单更新最多延迟 24 小时。本地复算与榜单分数的偏差本身是要记录的量。

## 非目标

- **Track 1（重建）与 Track 3（第一人称端到端）不参加。** Tier 3 需要的重建能力只为
  Track 2 服务，不单独优化 Track 1 的指标。
- **不改本体与仿真器。** G1 + Dex3 与官方仿真环境是赛题固定项。
- **不在 Tier 2 / Tier 3 使用 Tier 1 的干净轨迹**，包括作为训练信号、校准参考或
  挑选超参的验证集。
