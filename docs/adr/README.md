# ADR

**这里的每一份描述的是「当下的决定」，不是历史记录。** 决定变了就改正文，不留一段
已经不作数的推理。来龙去脉在 git 里，每份末尾的 `## 变更记录` 留一行摘要。

一份 ADR 管一个具体的架构决定，尽可能原子。文件名 `NNNNN-title.md`，号一经分配就
不改也不复用：源码注释、测试、契约表都会引用它。新增一律往后追加。
