## 2. 做法

| 段 | 集 | 对照（清单现在的 run） |
|---|---|---|
| `t1zt` | ep19、ep13 | `t1-ep19-w2048-cap10m-r3a-ml40`、`t1-ep13-w2048-cap10m-r3a-ml40` |
| `t1zt2` | ep7、ep3 | `t1-ep7-w2048-cap4m-p185g-mf4090`、`t1-ep3-w2048-cap10m-r3a-ml40` |
| `t1zt3` | ep22、ep16 | `t1-ep22-w2048-cap4m-mf4090`、`t1-ep16-w2048-cap10m-r3a-ml40` |

- 队列由 `make_var_queue.py t1zt|t1zt2|t1zt3` 生成，配方与 `t1zs` 相同：r3o seed 42、buffer 400 万、训练挂 `v040_p185_nfg_oo`。
  配方（支撑面、帧数、参考）取生成器读的 10/9 清单（`t1_select_r3x.tsv`）里同集的 run，表里的"对照"是现在的规则清单；两者不同的 ep3、ep16 支撑面、帧数、参考都相同，容量统一改成 400 万（复核核过）。
  `arm_var_chain.sh` 加 `t1zt*` 一档，同 `t1zs`。顺序按 MP-SR 期望从低到高，ep19 放第一段（唯一一集导出那一局 MP 失败的）。
- 起链：mf4090 没有链，先同步本 commit；三段的配置核对与预检都在起链前做完（`V2D_ALLOW_FC_SRC=1 V2D_FC_SRC=~/v2d/fc_src/v040_p185_nfg_oo`），`t1zt` 用 `arm_seg.sh` 起。
- 接力：`t1zt2` 等 `t1zt`、`t1zt3` 等 `t1zt2`，各用 `V2D_AFTER_INDEPENDENT=1 arm_after.sh`（三段的集互不相关），输出写 `runs/logs/arm_after_<段>_mf4090.log`。`t1zt3` 要等两段，设 `V2D_AFTER_MAX_POLLS=1200`（约 20 小时）。
- 每段带 `V2D_WANDB_PROXY=1`；冒烟要过 `plan-t3oo` 第 1 节的接线检查。
- 预计（MDT）：`t1zt` 约 17:00 导出完，`t1zt2` 约 22:00，`t1zt3` 11/01 约 03:00。
- **不同步窗口**：`arm_after` 发现 `.v2d-source-commit` 变了会停（第 6 步）。从起链到 `t1zt3` 记 ARM_AFTER_ARMED（约 11/01 03:00），不对 mf4090 跑 `scripts/dev/remote`；看榜与站点的提交只推 git，不同步 mf4090。

## 3. 判据（先登记）

- 每条 run 先过 `plan-t12night` 第 3 节的完好条件（训练、评测、导出都 DONE，否则记坏 run、不参与换集）。
- 换集规则与 `plan-t12night` 第 3 节相同（逐集、4096 世界期望、对清单现在的 run）：(a) MP-SR 高 ≥ 0.10 且 MPPE 不高 1 cm 以上；(b) MP-SR 差 < 0.10、SP-SR 高 ≥ 0.10，MPPE 同 (a)；(c) AUC 高 ≥ 0.03 且 MPPE 低 ≥ 0.5 cm，SP、MP 都不低 0.02 以上。
- 导出那一局只报"这样打包榜上会是多少"，不用来选 run，不为榜分重抽。
- 读法（只报）：六集里 ≥ 4 集换入，记"r3o 是 Tier 1 跟得住的集的默认配方"，剩下的跟得住的集（ep5、27、0、6 等）另写计划补生成器；2–3 集记"信号"；0–1 集如实报、不再铺。
- 提交条件不变（`plan-t12night` 第 3 节）：至少一个 Tier 1 榜按 Kaggle 同分规则前进至少一名、清单四项期望都不比 t1x1018 差，才问 rxzhou；Tier 1 每次上传都要 rxzhou 明确同意。

## 4. 风险

- 对照多数是 ml40 的 1000 万 run，r3o 是 mf4090 的 400 万：比的是"换不换"，不是 r3o 单独的效果；读法写明这一点。
- ep20 上 r3o 没满足规则；六集里可能有几集不换。不换的不影响清单。
- 接力停在中间（链失败或核对不过）卡会空到下次看榜；看榜时查 `arm_after_*` 日志最后一行。
- 磁盘：六条 run 估计 3–6 GB，可用 29 GB；低于 15 GB 先按备份规则清旧 state。
- 期望与导出那一局方向相反（ep20、ep21 有过）：清单照规则按期望换，榜分变差的榜不交。

结论 GO WITH FIXES（1 MAJOR、3 MINOR、2 NIT）。复核核过第 1 节的数字、六集的期望、榜与磁盘，并在内存里重跑生成器，12 个队列文件逐字节相同。
