## 2. 判据（登记）

- **健康**：冒烟通过；4096 世界 `non_finite_worlds` 为空；导出 EXPORT_OK。不健康的 run 不判、不重跑。
- **换集**（逐集，4096 世界，对 Tier 2 自己的参考；对照是第 0 节第 3 条 b1013 里同集的 run）：同时满足才换——

  只交 AUC 一个榜（`--only`），SP-SR、MP-SR、MPPE 三个榜不动（这三个榜上我们有同分，重交会刷新提交时间）。
  用 `tools/t2_swap_totals.py` 以 b1013 为基准算两个数：自己参考上导出那一局的 AUC 平均比 b1013 高 ≥ 0.010，**并且** 4096 世界的 AUC 平均比 b1013 高 ≥ 0.005，两条都满足才问 rxzhou；不够就不问、不交。
