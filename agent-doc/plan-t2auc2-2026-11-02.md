## 2. 判据（登记）

- **健康**：冒烟通过；4096 世界 `non_finite_worlds` 为空；导出 EXPORT_OK。不健康的 run 不判、不重跑。
- **换集**（逐集，4096 世界，对 Tier 2 自己的参考；对照是第 0 节第 3 条那条 1000 万变体 A）：同时满足才换——
  ADD-AUC 比对照高 ≥ 0.03；MP-SR 不低于对照 − 0.02；SP-SR 不低于对照 − 0.02；MPPE 不比对照高 0.5 cm 以上。
  同一集 400 万与 1000 万都满足时取 ADD-AUC 高的；差不到 0.01 时取 MP-SR 高的。
- **打包与上传**：以榜上 AUC 那份（b1013）为底，换入满足条件的集，算自己参考上导出那一局的 AUC 合计变化。
  只交 AUC 一个榜（`--only`），SP-SR、MP-SR、MPPE 三个榜不动（这三个榜上我们有同分，重交会刷新提交时间）。
  自己参考上的导出那一局 AUC 平均比 b1013 高 ≥ 0.0089（够过 FF）才问 rxzhou；问时写明偏差只量过一对、换跟踪方式时不成立（第 0 节第 5 条），以及 Kaggle 保留最好分，这一榜交低了不掉分。不够就不问、不交。
- 读数不改判据；读法另写，标明是解释。
