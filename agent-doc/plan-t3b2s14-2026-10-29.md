## 1. 做什么

1. **前提核对 P0（只用 Tier 3，过了才往下走）**：`t3_b2n_probe.py <root> tier3_cari4d_gb5_best_dr2s_dyn7 14 <gb5 训练 parquet> runs/t3b2/sym_t3fx.json 0 220`。
   - （i）层：报表里训练 parquet 对 `…_dr2s_dyn7` 层的刚体残差 ≤ 1 mm、≤ 0.01°；不满足说明 ep14 的参考不是由这一层出的，停，另查来历。
   - （ii）转轴竖直：每个静止段里转轴与地面法向夹角 ≤ 10°（绕竖轴转，底还在下面）。
   - （iii）桌面不动、动的是下半部：表面移动 p50 ≤ 2 cm，报表列出的最大移动点都在质心以下（沿转轴、朝地面那一侧）。
   三条都过，才算"第 0 主轴是桌面的轴，转动只改桌腿方向"；这三个门槛是看到第 0 节第 2 条的数之后定的，照写。
2. **选 g**（ml40，CPU）：`t3_frame0_table.py` 加 `--spin <episode,...>`：对列出的、不是离散对称的集，三根主轴各取一个候选（该轴网格角里右乘后差最小的那个）；整体取差最小的；要求原差 > 30°、右乘后 ≤ 30° 且至少小 20°、选中的轴就是 P0 核过的那根；**另外两根轴的最好候选只要有一个也 ≤ 30° 就拒绝**（同一根轴上相邻网格角必然也近，不算竞争）。记录列出三根轴各自的最好候选与差。写进选择文件，标 `"kind": "b2s"`、轴、转角、移动量。只对 ep14 跑。测试：合成形状上选回注入的轴与转角；另一根轴的最好候选也 ≤ 30° 时拒绝；轴与 P0 不符时拒绝。
3. **右乘**（ml40，t3sil）：`t3_b2_apply.py` 加只对一次调用生效的开关 `T3_B2_SPIN=<episode,...>`：对列出的集接受 `kind = b2s`，核轴、转角与选择文件一致；其余集照旧。在 `tier3_cari4d_gb5_best_dr2s` 层右乘（P0(i) 过了才确定是这一层），输出 `tier3_cari4d_gb5_best_dr2s_b2s14`；元数据记开关值、kind、轴、转角、移动量、选择文件与 Tier 1 文件的 sha256、规则版本。测试：开关下接受 b2s、不开关时拒绝、轴不对时拒绝。
4. **下游**：`T3FX_HR=tier3_cari4d_gb5_best_dr2s_b2s14 T3FX_SET=gb5b2s14dyn7 T3FX_DYN7_PHYS=runs/physics/tier3_cari4d_gb5_best_dr2s t3fx_build.sh 14`；motion、motion_src、Tier 3 根复制进主仓（根的 parquet 与 ground_plane 实拷、mesh 指 `../root_gb5/mesh`），`parquet_repath.py`、`check_inputs.py`；支撑面设置从原 run 的队列行读，核 `scene.support` 一致。
5. **H0（只用 Tier 3；不过就不训）**。H0 核的是流水线一致，**不核"整集错同一个转角"这个前提**（右乘 g 与 dyn7 可交换，前提不成立时 (a)(b) 照样会过）；前提只能由 P0 与 (f) 部分核、最终上榜才知道。
   - （a）锁定：新旧 dyn7 的 `held`、`locked_runs` 逐帧相同；锁定状态相同的帧，新朝向 = 旧朝向右乘 g 在 1e-3° 内，质心水平位置差 ≤ 1 mm；沿地面法向只报。（ep12 实测 0.000007°、0.000 mm。）
   - （a′）重定向只看人体：新旧训练 parquet 的关节与根逐帧差 ≤ 1e-4 rad、≤ 1e-5 m（ep12 实测 7.1e-5 rad、2.9e-6 m，来自重定向环境不同），左右手接触帧数各差 ≤ 5；超出先查清再训。
   - （b）训练 parquet 相邻帧转角 > 24° 的帧为 0。
   - （c）稳定与入地：按 1 cm / 2°、至少 15 帧的标准在整集里找全部静止段（不只物理检查记的两段；侧放、轮子朝上这类中途静止也算），每段右乘后静力稳定（`t3_rest_stable.py`）、最低点变化 ≤ 1 cm；全段物体入地帧数不比 gb5 dyn7 层多；`check_inputs.py` 过。
   - （d）新参考第 0 帧表：固定对齐下 ≤ 10°（预期 6.3°）；自动对齐只报。
   - （f）前提的部分核对（旧 gb5 参考，只用 Tier 3）：被拿着的各段里，物体绕第 0 主轴的转角在任意 10 帧窗口内变化 > 30° 的地方列出；有，说明重建中途可能换了支，常量 g 在那之后不对，停。
   - （e）只报：握着的手掌系中物体的相对朝向；右乘常量 g 不改变相邻帧的变化量，这一项只作记录。
6. **GPU（H0 过了才做）**：
   - ml40：段 `t3qb2s14`，由 `t3-ep14-w2048-cap10m-r3a-gb5-s43-ml40` 那一行手工派生（变体 A、seed 43、buffer 1000 万，只换参考目录与 run 名 `-gb5b2s14dyn7-s43-`），导出清单 `cand_t3_t3qb2s14_ml40.tsv`。队列与清单提交进主仓；**等 `t1za` 的链标记（含 `-gate`）全部消失后正常同步，再 `arm_seg.sh t3qb2s14 ml40`**，核 `runs/logs/arm_t3qb2s14_ml40.log` 出现 ARMED。不用 `arm_after`（它要在链跑着时就读 ml40 上的队列文件，而那时不能同步）。为了不空等，10/30 06:10 MDT 设一次性定时任务做这一步；若 t1za 那时没结束，定时任务只报、不动。
