## 1. 做什么

### A. 轮廓选朝向（不对称的翻转，只用 Tier 3）

1. 评估在**交付层**上做（gb5_dr2s_dyn7 的世界位姿，用 world 步的相似变换映回 exo 相机，同 `t3_frame_confidence.py` 的 `silhouette()`），不在 CARI4D 原始位姿上做——要改的是交付给训练的那一层。
2. **候选**：对每帧位姿右乘绕网格三条主惯性轴的 180°；网格有一条连续或 n 重近似对称轴时（杯子、瓶子、锥桶、圆桌），另加绕这条轴每 30° 一个。凡是 `t3_symmetry.symmetries()` 认成对称的旋转不进 A（轮廓看不出、交给 B）。
3. **分段**：按原数据里单帧转角超过 `t3_dynamics_check` 的跳变阈值的帧、与手的接触状态变化处切段；每段至少 10 个有掩码证据的帧（可见掩码 ≥ `MIN_MASK_PX`），不够的段不判。
4. **判**：每段用 `choose_pose`（门槛不改：0.5 / 0.05 / 0.05）；`accept` 的段用 `right_multiply` 换掉这一段的旋转，平移不动。段边界上新旧朝向不一致处，按 dyn7 第 3 步的做法在 0.5 s 内余弦过渡。
5. **能分辨的检验（先做，没过就不往下走）**：在交付层上挑判为 `current-best` 且中位 IoU ≥ 0.7 的段，人为右乘一个已知的候选旋转当“错的输入”，看 A 能不能把它判回 `current`。逐个候选旋转报召回；某个候选旋转召回 < 0.8 的，A 里不用它（轮廓分不出它）。

### B. 对称物体的朝向

1. **B1 贴图（只用 Tier 3）**：对第 0 节第 4 条认成对称的物体，以及第 2 条表里绕近似对称轴转错的物体，把对称等价的候选各渲染一份带贴图的图像，与视频帧在掩码内（去掉人体像素）比颜色：
   亮度与色度先按掩码内的均值方差归一化，打分用逐像素的归一化互相关，按段取中位，判法同 A（门槛 0.5 改成“最好与第二好之差 ≥ 0.05 且 ≥ 3 倍于段内逐帧分数的标准误”，因为互相关的量纲与 IoU 不同；数值在第 1 版先这样登记，复核可改）。
   先做两项检验：（a）贴图本身能不能分：同一位姿下两个候选的渲染图互相关 ≥ 0.95 的，记“贴图分不出”，B1 不判这一对；（b）同 A5 的人为翻转召回，召回 < 0.8 不用。
2. **B2 第 0 帧对齐（读 Tier 1 第 0 帧，默认关）**：只对 B1 判不了的物体，在它的对称群里（n 重轴取 n 个、连续轴每 5°）选一个元素，使第 0 帧的物体朝向最接近 Tier 1 第 0 帧；整集右乘这一个元素。
   因为右乘的是对称元素，画面、轮廓、物理接触都不变，改的只是物体系怎么定，与 10/21 的世界系偏航对齐是同一类操作。官方 FAQ（10/19）允许“用 Tier 1 第一帧计算对齐，前提是 Tier 1 的 caption 不在 Tier 3 别处使用”；
   把物体系的对称规范算进“对齐”属于解读，**用不用待定（rxzhou，必要时问组委会）**。实现成单独的变体 `_f0sym`，与主线分开出数据，没有明确同意不进训练、不进提交。不对称的转错（A 管的）不用 B2 修。
3. **连续对称在操作中的转动**（碗、瓶子被手转着走）：几何与贴图都看不出时，只能靠“抓稳时物体相对手不转”从人手推。第 1 版不做，记为已知；A、B 做完再看要不要另写计划。

### C. 手碰到前物体就动

1. 推广 `t3_onset_one.py` 到交付层的全部 30 集：在没被碰（手到物体表面 > `HAND_M`）的帧里，比较参考里的物体位移与视频掩码的位移（质心像素位移、与段首掩码的 IoU）。
2. **分两种**：
   - **物体侧漂移**：参考里物体移动超过 3 cm，同一段视频掩码质心移动 ≤ 15 px、与段首掩码 IoU ≥ 0.8、人体掩码不压物体（重叠 ≤ 5%）。这是重建在漂，物体其实没动 → 这一段锁成一个位姿（取段内有掩码证据的帧的稳健中值：平移取中位，旋转取弦距均值），段尾到手碰到时 0.5 s 余弦过渡。
   - **手迟到**：视频掩码确实在动、而重建的手还没到。物体轨迹是对照真值计分的那条，不改物体；记下来，第 1 版不修人体（要修是让手在物体动之前到位，属于重定向一侧，另写计划）。
   - 其余记“判不了”，不改。
3. 改完的段重跑 dyn7 之后的步骤（物理检查、支撑面、usda、重定向），支撑面按新的静止段重新算。

### D. 出数据

1. 只读复制其余 27 集的掩码与 CARI4D 输出到我们的目录（`t3r_` 系列脚本的同一套只读防护）；在我们的副本上以 gb5_dr2s_dyn7 为输入，依次做 C、A、B1（B2 另出变体），出新版 `t3fx`（名字只用小写字母与数字，`paths.py` 的约束）。
2. 版本只交给我们自己的训练，不改她的目录。

- **G0（能分辨）**：A5、B1(b) 的人为翻转召回按候选旋转逐个报；召回 < 0.8 的候选不用。所有候选都不过的，A 或 B1 整项记“轮廓 / 贴图分不出”，不出数据。

## 3. 风险

- A 在 ep04 整集上已判不了；分段后也可能大多判 `current-best`。G0 先挡住分不出的候选，避免把对的改错。
- B1 可能和以前的零样本特征一样分不出；那样对称物体只剩 B2，而 B2 取决于规则解读。
- C 锁错段会让物体在真的被推动时不动；“物体侧漂移”的判法要求掩码不动、人体不压物体，宁可判不了。
- 换了参考，策略要重训才能见分；8 天里训练和一次 Tier 3 提交都要排上。
