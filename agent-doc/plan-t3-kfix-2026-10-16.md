## 定下的量

- 内参 K_t：吊顶方格拟合 GB 的 f 866.3、cx 701.8、cy 531.1（`results/t3world/ceiling_grid_main9.txt`）。取 GB 而不取 G：GB 用已核实的世界竖直方向 n
  补主点到地平线距离那一个量，cy 的自助法区间 [530.8, 531.4]，G 的是 [530.3, 539.2]。偏航 A/B 用的是 3 段视频的 G（866.2、702.0、533.3），
  与 GB 的 cx 差 0.2 px，cy 差 2.2 px（俯仰 0.15°）。cx 的取值经过一次榜单 A/B（一位信息，rxzhou 同意），在此重申。
- 地面：发布地面平面经另一位用户的 `t3_inputs.read_plane` 读（会拒绝 foot_plane_dist_stats），主机位组的平均法向与 d 中位，同 `t3_floor_fit.py`。

## 方案

1. 重新表达（新脚本 `stages/recovery/t3_kfix.py`，ml40 的 v2d_cari4d 镜像里跑，只用 CPU）：读 `runs/convert/<集>/` 的 `object_cam.npz` 与
   `soma_params.npz`（CARI4D 相机系、内参 K_c）。逐帧：物体网格原点的像素 p = K_c t（齐次后取前两维），新视线 r = K_t⁻¹ [p, 1]；深度两种口径，
   都是线性映射 diag(1, 1, k)·K_t⁻¹K_c：口径 Z（z 不变，k = 1）与口径 F（z 乘 f_t/f_c）。物体朝向随视线转（`t3_convert_ep.py` 的 `_ray_turn`）；
   人体骨盆按同一映射，根随视线转，其余关节刚体跟随（`_move_body`，逐帧核关节，误差上限 1 mm）。随视线转是对剪切的一阶近似：中心精确，
   0.5 m 的物体边缘约 4 cm、骨盆到脚约 5 cm；核对 c 专门看大物体与人脚。
2. 地面校正：用同一批 714 个主机位地面事件（`t3_camera_height.py` 的 event_rows），在新表达上按 `t3_floor_fit.py` 的方法重拟 R_floor′ 与 s′，
   再像交付版世界步一样作用到物体与人体（含按 s′ 缩放人体）。
3. 不用真值的核对：
   a. 几何：新表达（地面校正之前）上拟出的地面相对发布地面的俯仰分量、横滚分量、接触点高度随深度的斜率；与流程焦距步之后、世界步之前的相机系比
      （`results/t3world/floor_tilt_k.txt` 的 P 行：俯仰 −3.69°、横滚 −1.05°、斜率 +6.59 cm/m）。
   b. 人脚：支撑脚（逐帧最低的脚关节）在地面校正之后离发布地面的高度，中位与 90% 分位。
   c. 画面对齐（口径自洽核对，不作门槛）：新参考按 K_t、恒等世界步投回画面，与 SAM2 掩码比轮廓 IoU，分口径、分物体与人体算。要给
      `gate/t3_align_check.py` 加“按给定内参、恒等世界步”的选项（现在它用 object_cam_focal ↔ object_world 拟相似变换、按 K_830 投影）。
4. 落地（每一步都要新写或改工具，见下一节）：新参考写成一个 Tier 3 版本目录（Tier 2 schema）→ 支撑面在新版本上重做（`t3_support` →
   `t3_support_usda` → 门槛）→ `tier3_expect.py` 生成期望表并提交 → 白名单加新版本名 → `tier3_stage.sh` 拼进 mf4090 的新 root → 重定向 7 集 →
   用现有 checkpoint 对新参考跑 4096 世界评测与 1 世界导出（覆盖 task.parquet）→ 按导出 JSON 里的新参考目录生成 frame refs → 新集（不转偏航，
   K_t 已含偏航）与没换的集（沿用 gridG_yaw 转过的 frame refs）合并成一个目录 → 打包、核对。
5. 提交与否由 rxzhou 决定。

## 判据（第二版；其中第 1 条是看过 `floor_tilt_k.txt` 之后改的，单独标注）

1. 几何（事后修订，看过结果后改）：第一版登记的“倾斜 ≤ 1.0°”已经不过（G 1.32°、GB 1.22°），且定错了地方——横滚分量约 1° 在每一套内参下都在，
   包括流程原来的内参，不归内参管。改为：口径 F 或 Z 的俯仰分量 |·| ≤ 1.0° 且接触点高度随深度的斜率 |·| ≤ 2.0 cm/m（流程相机系是 −3.69°、
   6.59 cm/m），记“标定内参解释了地面的俯仰”；不满足就停。横滚交给方案 2 的地面校正。
2. 地面校正的预测（跑之前登记）：R_floor′ 的倾斜在 0.8°–1.8° 之间、以横滚为主（交付版是 3.83°），s′ 在 0.97–1.00 之间（交付版 0.9856）。
   落在外面记“地面校正与预期不符”，停下来查，不往下做。
3. 口径：按 `t3_floor_tilt_k.py` 已登记的规则，取接触点高度中位的绝对值小的那个；两者相差不到 0.5 cm 取口径 F。
4. 人脚：地面校正之后支撑脚高度中位的绝对值 ≤ 3 cm（交付版人体也按地面缩放过，作对照一并报）。超过就停。
5. 重新导出后逐集看对新参考的本地 MP-SR 与 SP-SR（4096 世界）：两者都不低于旧参考的值减 0.05 才换成新参考；旧参考 MP-SR 为 0 的集（如 ep20）
   只看 SP-SR。不满足的集保留旧参考、旧 rollout 与 gridG_yaw 的 frame refs。
6. “新参考是不是更好”没有不用真值的检验：交付版的静置帧被 `t3_depth_post.py` 按到地面上，按构造离地很近，不拿来比。这一问只能靠榜单 A/B，
   交不交、怎么判由 rxzhou 决定；若决定做，判读规则在交之前另行登记。
7. 任何一步不读真值、不读 Tier 1、不读 Tier 2 轨迹；不按榜上分数挑参数。

## 风险

- CARI4D 物体深度的来源（已知网格视大小还是 MoGe 度量深度）没核实；两种口径都做、按地面选。
- 新参考里人和物体的相对位置会变（随视线转的近似、两者深度不同），现有策略可能跟不住；判据 5 会把这样的集挡回旧参考。
- 新参考在榜上是否更好，开发期没有检验办法（判据 6）。
