## 2. 判据（登记）

- **P1 逐条（4096 世界，Tier 2 对自己的 v5.4 参考，Tier 1 对 Tier 1 参考）。** 与这一集现在交的 run 比：现在 MP-SR < 0.5、新 run ≥ 0.5 记“修好”；
  MP-SR 升 0.2 以上或平均位置误差降 30% 以上记“变好”；其余“没用”。对照 ep16（现在 MP-SR 0.938）：r3p 降到 0.838 以下记“r3p 伤了跟得好的集”，不铺开。
- **P2 选集。** 照登记的规则：Tier 2 用 select_t2（4096 世界 MP-SR → AUC），Tier 1 用 select_t1（导出 MP-SR → SP-SR → AUC / 0.3780 − MPPE / 25.1706）。
- **P3 交不交（有把握拿第一才交）。**
  - Tier 1：打包的本地 MP-SR ≥ 0.80000（24/30）才交（Tier 1 导出的本地分数就是榜上的分数，FF 是 0.76666）。
