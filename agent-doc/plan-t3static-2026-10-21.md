5. **改参考的工具现成**：`stages/retarget/hands_off.py` 把两条手臂与手指固定为一帧、接触标记清零、手掌按正向运动学重算，其余列与 object 目录照抄。

8. **算力**：mf4090 约 19:30 MDT 空（t2mtr 训评完）；ml40 约 23:30 空（t3g5 B 段）。一集冒烟约 4–5 分钟、4096 世界评测约 5 分钟、导出约 3 分钟。Tier 3 额度 10/22 16:14 MDT 起。

## 1. 做什么

1. **站立参考**（CPU）：`hands_off.py` 加 `--stand`：机器人全部关节、根位置、根朝向在全部帧都换成第 0 帧的值；`ee_pose_w` 按正向运动学重算（沿用现有自检：原关节角下算出的手掌与原 `ee_pose_w` 差 ≤ 2 mm）；
   `hand_contact_active` 全部置 0；object 目录、物体轨迹列、支撑面、`v2d_meta.json` 照抄。报告：第 0 帧机器人各连杆点到物体表面的最近距离（物体停在第 0 帧位姿）。
   测试 `stages/retarget/test_hands_off.py` 加一条：机器人列全帧相同、物体列逐字节相同。参考版本取 t3m1022a 里这一集用的那一版（帧参考已对齐，不用重做）。
2. **自参考的“不动”分**（CPU）：新写 `stages/evaluate/t3_static_floor.py`（照 `t2_static_floor.py`，同一套官方公式 `v2dlb/object_pose.py`，挂 `forbid_lower_tiers`）：
   对每集参考，物体一直停在第 0 帧时对这份参考的 MPPE、ADD-AUC、SP-SR、MP-SR。与 t3m1022a 里各集 run 的 4096 世界对自己参考的读数并排成一张表（`results/t3static/select_table.txt`）。
3. **选集（登记的规则，见第 2 节 S3）**：只看这张表，定哪些集换成站立保底。
4. **冒烟、评测、导出**（GPU）：`make_var_queue.py` 加段 `t3pst`（mf4090）与 `t3qst`（ml40）：只跑冒烟（4096000 步，`training.checkpoint.save_interval_environment_steps=409600`），
   每集先量第 409600 步的残差头（S1），再用 `V2D_EVAL_STEPS=409600` 评 4096 世界、导出 1 个世界。先在 mf4090 上做试点 3 集（S2），过了再铺开；ml40 空了分一半。
5. **拼清单**：t3m1022a 换上站立保底的集，名为 **t3m1022s**。新 run 的参考 parquet 换了（sha256 变了，物体轨迹不变），帧参考按新 parquet 用 `make_frame_refs_t3.py` 重新生成，
   再用 `align_frefs_t3.py` 按这一集在 t3m1022aa 里的方案（obj / yaw_obj / yaw_hum）对齐，核对新旧对齐变换差 ≤ 1e-6；其余集沿用 t3m1022aa 的帧参考。打包、预演、`csv_frame0_check.py`、逐集比 CSV。
   t3g5 已过 R1 的 ep12（gb5 参考）另做一版 **t3m1022s12**：ep12 换成 gb5 的 run，帧参考按 gb5 参考生成后用同一对齐规则对齐。两版都不上传。
6. 结果写进本计划执行记录，交 rxzhou 定交不交、交哪一版。

## 2. 判据（登记，第 1 版）

- **S0（站立参考）**：每份新 parquet 机器人关节、根位置、根朝向全帧与第 0 帧逐位相同；物体位姿列与原 parquet 逐字节相同；手掌自检 ≤ 2 mm。不过的集不用。
- **S1（零残差）**：第 409600 步的残差均值头（与 t12replay 同三个张量）最大绝对值 = 0。不为 0 的集不进候选（动作不再只取决于参考）。
- **S2（试点：物体真的不动）**：试点 3 集 = ep16（瓶子在约 1 m 高的台面上）、ep27（篮子在地上）、第 1 步报告里机器人离物体最近的一集（与前两集重复就取第二近）。
  每集 4096 世界对自己参考的 MPPE 与第 2 步算出的“不动”分差 ≤ 1.0 cm，且导出的 1 个世界里物体离第 0 帧位姿全程 ≤ 2 cm、≤ 5°。
  3 集都过 → 铺开；1 集不过 → 那一集不用，其余铺开；≥ 2 集不过 → 停，记“站立保底不成立”，另写计划。
- **S3（选集，只用 Tier 3 的读数）**：一集换成站立保底，当且仅当 t3m1022a 里这一集 run 的 4096 世界对自己参考的 MPPE > 这一集参考的“不动”MPPE（第 2 步）。
  ADD-AUC 并列报，不进规则。对齐后朝向仍差 > 30° 的 10 集照同一规则判（站着不动时朝向误差照样进分，与策略一样）。
- **S4（清单）**：t3m1022s 打包 `PACK_OK`、预演通过；`csv_frame0_check.py` 对 t3m1022a 的旧 CSV `CSV_FRAME0_OK`；与 t3m1022aa 逐集比，内容不同的恰好是 S3 选中的集。t3m1022s12 另外只多 ep12 不同。
- **不做预测**：对齐与保底都只能交上去才看得到对真值的分；第 0 帧偏差与自参考读数都不当作榜上分数的预测。交不交照策略第 1 节由 rxzhou 定，这一轮不上传。

## 3. 风险

- 站立的机器人可能慢慢倒；倒在原地、离物体远就不碰物体。S2 管的就是这一条；离物体近的集（第 1 步报告）倒下可能碰到，S2 不过的集不用。
- 物体自己掉：参考第 0 帧若悬空或穿进支撑面，仿真开局就会动（10/15 的“从台面掉落”）。S2 的 ep16 测这一类；铺开后每集都看 S2 的第二条（导出世界里物体位移）。
- 自参考是重建结果，不是真值；“不动”对自己参考的分与对真值的分不同。规则只拿它在同一份参考上比策略与“不动”，不推到真值。
- 规则读法：站立保底是一份真的 checkpoint、在官方仿真里跑出的轨迹；规则里没有禁止“机器人不去做任务”的条文。这是解读，封榜后组委会怎么看未知。
- mf4090、ml40 各占约 2–3 小时；不占正在训的 run（等 t2mtr、t3g5 B 段结束）。
