## 0. 事实（都有出处）

1. 策略第 2 节把 **Tier 2 的 MPPE 与 AUC** 排在算力第一位：30 集的 4096 世界 MPPE 合计约 540 cm，ep25、ep4、ep28 三集约 290 cm（`agent-doc/strategy-2026-10-19.md`）。
2. t2term（ml40，buffer 1000 万，seed 42，`termination.object_position_threshold` 0.1 → 0.3）的最终 checkpoint，4096 世界、对自己参考
   （`results/ml40/day2/eval_t2-ep2{5,8}-w2048-cap10m-r3a{,-ot3}-ml40_s349999104.txt`）：
   ep25 MPPE 123.93 → 72.25 cm、ADD-AUC 0.116 → 0.152；ep28 MPPE 58.69 → 38.69 cm、ADD-AUC 0.105 → 0.076。
   按 t2term 登记的 M 两集都不过，T 没判；事后观察是回合变长、物体终止少 0.10–0.13、手掌终止多 0.11–0.13（`agent-doc/plan-t2term-2026-10-20.md` 执行记录）。
   那份计划写明下一步：在同一集上换种子或换阈值重复，并查 ep28 的 AUC 为什么掉，另写计划——就是这份。
3. 单个种子的离散：ep25 同一 run 各 checkpoint 之间差 23 cm（106–129，t2term 第 3 节）。mf4090、buffer 400 万的 ep25 对照：变体 A 前的基线 117.09 cm / AUC 0.124
   （`results/day2/eval_t2-ep25-w2048-cap4m-mf4090_s349999104.txt`），r3a-c5 126.57 / 0.127。mf4090 上没有 ep28 r3a、400 万的对照（只有 p185：60.36 / 0.077）。
4. “物体不动”的底线（与机器无关，`results/t2diag/t2_static_floor.txt`）：ep25 49.51、ep28 48.49、ep4 111.51 cm；ep4 现在交的导出 111.48，等于底线。
5. 机器：`arm_var_chain.sh` 的 `t2m*` 分支指向 mf4090（4090、buffer 400 万的设置），`t2t*` 只指向 ml40；所以段名取 `t2mtr`。mf4090、buffer 400 万一集约 2.3 小时（`agent-doc/plan-t3g5-2026-10-21.md` 第 36 行的实测），加冒烟、评测约 2.6 小时。

## 1. 做什么

1. `make_var_queue.py` 加清单 `t2mtr`：Tier 2、mf4090、buffer 400 万、seed 42、变体 A 加 `termination.object_position_threshold=0.3`（冒烟与正式都加，同 t2tm），
   run 名 `t2-ep{ep}-w2048-cap4m-r3a-ot3-mf4090`，顺序 **ep25、ep4、ep28**（复核 5：显存不足跳过链尾时，丢的是不改主判断的 ep28）。生成期望表、冒烟、正式队列与导出清单。
2. 同步到 mf4090（`scripts/dev/remote`，来历干净），`stages/policy/arm_seg.sh t2mtr mf4090`：配置核对、预检、起链预演、起链；核展开配置里 0.3 在 termination 与 env.termination 各一处。
3. 训、评（4096 世界，只评最终 checkpoint）、导出照常；约 8 小时，预计 10/21 20:30–21:30 MDT 结束。
4. ep28 的 AUC 为什么掉，这一轮不查（复核 2：逐帧逐世界的 ADD 只有 GPU 上的 `diag_rollout.py` 出得来）。summary 里已有的事实：ot3 对照 ep28 朝向误差 47.3° 对 101.0°、平均 ADD 0.447 对 0.750 m，
   朝向与平均误差都变好而 AUC 变差，所以不是朝向变差；多半是 AUC 只数阈值以下的帧，误差整体降了却没降进阈值。要查另写计划、排 GPU 时间。

## 2. 判据（登记，第 2 版）

- M（覆盖进了训练）：展开配置里 termination 与 env.termination 各有一处 0.3（`arm_var_chain.sh` 的断言）；W&B 汇总里回合平均长度比同集 ml40 对照长（ep25 109.5 步、ep28 195.7 步、
  ep4 取 ml40 `t2-ep4-w2048-cap10m-r3a-ml40` 的训练终止表）。M 不过的集记“覆盖没进训练”，不判下面各条。
- 只比最终 checkpoint，4096 世界、对自己参考。对照一律取**每个指标上最严的那个**（复核 3）。门槛分两档（复核 4：同一 run 内 checkpoint 之间就差 23 cm）：降 ≥ 23 cm 记“成立”，降 10–23 cm 只记信号。
  mf4090 上成立的意思是“变体 A 加 ot3 胜过现在交的导出”，不单证明 ot3 本身有用（对照与本次不止差 ot3 一项）。
  - **ep25**（重复）：MPPE ≤ 117.09 − 23 = 94.09 cm（对照 117.09、126.57 里低的），且 ADD-AUC ≥ 0.127 − 0.01 = 0.117（对照 0.116、0.124、0.127 里高的）。ml40 那次（72.25 cm、0.152）按同一门槛也成立。
    两次都成立记“放宽对 ep25 有用”，再低于底线 49.51 cm 记强档。
  - **ep4**（外推）：MPPE ≤ 111.49 − 23 = 88.49 cm，且 ADD-AUC ≥ 0.114 − 0.01 = 0.104（对照 `results/day2/eval_t2-ep4-w2048-cap4m-mf4090_s349999104.txt`，111.49 / 0.114；
    底线 111.51 与它几乎相同）。单个种子，成立也只记“外推有信号”，要推到导出前另做重复。
  - **ep28**（问题改成“ml40 上的取舍会不会重复”，复核 1）：MPPE ≤ 58.69 − 10 = 48.69 cm 记“MPPE 的降重复了”；同时 ADD-AUC < 0.105 − 0.01 = 0.095 记“AUC 的掉也重复了”。
    两条都中，记“ot3 在 ep28 上拿 AUC 换 MPPE”，ep28 不单独换（AUC 与 MPPE 是两张榜，换不换按策略第 1 节两张一起算）；只中 MPPE、AUC 不掉，按 ep25 的门槛判成立与否。
- ep25 不成立，就不往其余举起类集推；ep25、ep4 都不成立，下一个候选是 VOC 课程（t2term 第 2 节），另写计划。
- 导出那一局并列报，不按它判；不按榜上分数挑东西。
- 这一轮不提交。成立后要交，照策略第 1 节：期望与公开都要按 Tier 2 的余量领先，预测要用至少 2 对同类换集的提交验证过的传递（`agent-doc/strategy-2026-10-19.md` 第 1 节；自参考到榜的传递不可靠，b1019a 的教训）。

## 3. 风险

- 机器与 buffer 都换了（mf4090、400 万），与 ml40 那次不是只差种子；好处是两次互相独立，坏处是不成立时分不清是种子还是 buffer。读数时写明。
- ep4 放最后：前两集的冒烟或正式训练若显存不足（退出码 4）会跳过其后的 run（t2mx 复核 2 的写法），ep4 丢了不影响主判据。
- `-ot3-` run 的 chord_sr 与失败原因比例按 0.3 m 算，与对照不可比（t2term 第 3 节已核实）；判据只用 MPPE、ADD-AUC。
