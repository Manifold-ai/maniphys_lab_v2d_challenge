## 1. 惩罚加在哪里（判断与理由）

- **不加在策略奖励里。** 奖励与终止只决定仿真物体跟参考跟多紧，它不带任何关于真值的信息。参考错的地方，跟得越紧离真值越远（事实 2）。仿真本身倒是一道物理滤波：刚体不能一帧转 150°，σ 0.4 的 ep15 正因此留在了翻转前那一支。但这种滤波是碰巧的，对自己参考的读数还会把它算成失败，不能拿来选 run。
- **加在重建里，用真值一定满足的物理约束。** 被拿着或在空中的刚体，角速度有上限，不会在 0.2 s 内转 150°；被拿着的物体相对手掌的朝向基本不变；放在地上的物体静止、立得住、不穿地。dyn7 的锁定与去跳变已经是这几条的硬约束版本。这一份补上的缺口只有一处：不对称物体在被拿段里切了支，而切过去那一支一直延续到最后的歇着段（ep15），现有工具不碰歇着段，所以拒改。
- **不用接触作条件。** "没碰就不许动"在数据里不成立（事实 4、5），这类约束只会把真实的搬运锁死。
- **对称物体的选支没有物理约束能定。** 两支在形状上一样，物理、轮廓、连续性都分不出，只能靠第 0 帧的锚点，这就是 B2。

### 第 2 步：ep15 的两个分支变体（重建，CPU）、判支与重训（GPU）

仿真跟得住 Tier 1、Tier 2 的 ep15（事实 3），这和两种真相都对得上：要么人根本没把牌子转过去（风暴是重建切支，回转对），要么人在换手的那一段把牌子慢慢转了一百多度（Tier 3 右手接触 480–531 断开，Tier 2 右手接触 497 才开始，`slip_*_ep15.txt`；任务是"拿起、搬、放回地上"），重建把这段转动压成了一帧。连续性分不出这两种，所以两个变体都出，用最后歇着段（626–715：静止、没有手、可见）判。

1. **变体 R（回转）**：`t3_held_fix.py` 加只对一次调用生效的开关 `T3_HELD_FIX_CARRY=1`（默认关，值进来历）。条件：被拿段里只有一个切换风暴、物体不对称（群只有恒等）、段末对下一个歇着段差 D 超过上限。做法：
   - 风暴处重置得到的物体系修正 C 从风暴末帧 b 起一直右乘到集末（含歇着段 626–715），绕质心转；
   - 这时段末的剩余差 D′ 只等于输入自己在 625/626 帧的连续性（C 是常量右因子，与哪一支对无关），**只报、不作闸门**；D′ 只扩散在风暴末帧之后的帧上（余弦权重从 b 起），风暴之前的帧一帧不动；
   - 歇着段转过之后，沿地面法向平移，让凸包最低点回到输入歇着段的最低点高度（报平移量）。
   - 风暴帧（497–502）按现有做法插值。
2. **变体 S（摊开）**：不回转，歇着段与风暴之后的位姿保持输入；只把风暴那一跳摊到风暴两边的一个窗口 [a, b) 上。`t3_held_fix.py` 另加只对一次调用生效的开关 `T3_HELD_FIX_SPREAD=a:b`（值进来历）：在子段 [a, b) 上调 `unwrap_run`（`match_end=True`、目标取输入第 b−1 帧），这条路绕过 `max_d` 与 `MAX_SPREAD_DEG` 两道上限（D ≈ C 的转角本来就超），`processed` 与 `changed` 只限于子段。
   窗口按转速定、不按接触标记定：以风暴（497–502）为中心向两边对称扩，取使余弦扩散的单帧峰值（π/2 × 转角 / 窗口长）≤ 6°/帧（`RETURN_RATE_DEG`，远低于 24°/帧的跳变口径）的最短窗口，最长 90 帧；超了就不出 S。报最终窗口。第 a 帧之前与第 b−1 帧起与输入逐字节相同。
3. 两个变体各出一版：`tier3_cari4d_gb5_best_dr2s_hr3r`、`…_hr3s`（只 ep15）→ `t3fx_build.sh 15`（物理检查 → dyn7 → 物理检查 → 重定向、usda，集名 `gb5hr3rdyn7`、`gb5hr3sdyn7`）→ 训练用的 motion parquet。
4. **构造性检查（两个变体都要过，不过说明代码错了）**：dyn7 层与 parquet 相邻帧转角 > 24° 的帧为 0；R 在第 497 帧之前、S 在第 a 帧之前与第 b−1 帧起与输入逐字节相同；动力学违规帧不增加；`check_inputs.py` 过。
5. **判支（登记，只看最后歇着段 626–715，dyn7 锁定后的位姿）**：
   - （d）静力稳定：凸包里离地 ≤ 1 cm 的点作支撑多边形，质心沿地面法向的投影落在里面。两版各判一次；
   - （t）贴图（`t3_fix_tex.py`，`gap=0.27 nulls=tilt`，与 `plan-t3flip13` F0 过的设定相同）：在 R、S 两版的 dyn7 层上各跑 ep15，看覆盖 503–715 帧的段。R 层判"当前"、且 S 层判出一个与 C 夹角 ≤ 20° 的候选 → 贴图支持 R；S 层判"当前"、且 R 层判出一个与 C⁻¹ 夹角 ≤ 20° 的候选 → 支持 S；两层不一致、或都没有判出 → 贴图沉默。ep15 自己的负对照候选（±5°、±10°、平移 1 px、换采样点）有任何 accept，贴图记沉默；
   - （e）轮廓 IoU 只报（R 对 S 的逐帧差、中位与块自助 95% 区间）：输入歇着段的位姿是重建对着这些掩码拟合出来的，R 只是把它整体转过去、没有重新拟合，IoU 天然偏向 S，不作依据；
   - 规则：一版稳定、一版不稳定 → 选稳定的；都稳定时看（t）：支持哪版选哪版；沉默就记"分不出"。都不稳定 → 停，ep15 不训。
   - 只报、不作依据：C 的转轴与地面法向的夹角；风暴两端在输入上的隐含角速度；两只手的掌系里物体的相对朝向（`stages/retarget/ref_hand_object_turn.py`；每侧按离物体的距离挑手，不用接触标记），风暴前后 30 帧的中位差，以及两只手掌在 497–502 帧自己的单帧转角；贴图一致性（`t3_fix_tex.py`，门槛 0.27）；Tier 2 官方参考 490–510 帧物体的转角；两版第 0 帧朝向差（第 1 步的工具，两版第 0 帧相同）。
6. **先用现有 checkpoint 重新评测导出**（ml40，`V2D_EXPORT_PARQUET` 指向选中那版的 parquet；"分不出"时两版都做，4096 世界加导出一局）：`t3-ep15-w2048-cap10m-r3o-gb5-ocoff-sg04-ml40` 与 `t3-ep15-w2048-cap10m-r3a-gb5-ml40`，约 20 分钟一条。
7. **重训**：选出一版时，ml40 变体 A seed 42、mf4090 变体 A seed 43，都用选中那版；"分不出"时，ml40 训 R、mf4090 训 S（各 seed 42），两条都标"分支未定"。run 名带集名（`-gb5hr3rdyn7-` / `-gb5hr3sdyn7-`）；队列用 `make_var_queue.py` 生成，`arm_seg.sh` 起链，读数用 `t3g5_readout.sh`。
