## 门槛（评测器原文）

`results/batch1/metric_threshold_facts.txt`（flash_chord v0.4.0 `evaluation/metrics.py:21–24, 296–349`）：本地评测器按世界判，每个世界先对帧取平均误差再比门槛。
`maniptrans_success`（MP-SR）：位置 < 0.03 m 且朝向 < 30°；`spider_success`（SP-SR）：位置 ≤ 0.1 m 且朝向 ≤ 0.5 rad（28.6°）；chord_sr：整条参考走完、途中没越过跟踪阈值（宽松得多）。
我们报的 MP-SR / SP-SR 是 4096 个世界里成功的比例；排行榜上每条 episode 只评 1 个世界，按 episode 计（kit README 用的是同样的门槛）。

## 22 条放在一起看

同一张表的 22 条（逐帧满配、最终 checkpoint、已判定）：MP-SR ≥ 0.95 的 4 条（ep12、ep8、ep23、ep26）都是在地面上推或转的大件，没有支撑面；
彻底失败（chord ≤ 0.19、平均位置 > 29 cm）的 6 条（ep4、ep9、ep11、ep25、ep2、ep3）都是半径 0.13–0.29 m 的小件，运动占比 70–90%，总转角 759–3217°。
秩相关（事后描述，不作检验）：总转角对 MP-SR −0.69、对 chord −0.68；路程对 MP-SR −0.68；运动占比 −0.50；单段最大转角 +0.10；物体半径 +0.26。
难度跟“一共要转多少、走多远”有关，跟某一下转得多猛关系不大。

## 训练过程（按课程阶段，每段最后 25% 的均值）

`results/batch1/wandb_by_stage_ml40_b.txt`（`stages/policy/wandb_local_history.py --by-stage`，读本地 .wandb）。课程让 VOC（给物体的虚拟辅助力）从 1 分段降到 0（第 6 段起为 0），
最终评测时没有 VOC。

- **ep23**：各段参考进度 0.94–0.96，走完参考 0.90–0.95，物体终止 2–5%；VOC 降到 0 几乎没影响，朝向误差 0.09 → 0.18 rad。
- **ep15、ep17（朝向跟不住）**：物体一直在手里（进度 0.92 左右、0.8 左右），但 VOC 撤掉的过程中训练时的物体朝向误差一路涨：ep15 0.11 → 0.53–0.55 rad，
  ep17 0.11 → 0.61–0.64 rad；位置误差基本不变（约 4 cm）。ep15 只有右手接触（0 / 434），单手拿一块薄板，朝向靠辅助力才稳。
- **ep19（有辅助也跟不上）**：VOC 全开的第 0 段进度只有 0.32，物体终止 58%；最好到 0.61，VOC 撤掉后回落到 0.54。
- **ep25（辅助一撤就掉）**：第 0–1 段进度 0.68–0.70；VOC 每降一档进度就掉一截，第 8 段只剩 0.22，物体终止从 25% 升到 78%，走完参考从 0.55 降到 0.05。
  2475° 的连续转瓶子，靠辅助力时还能跟一部分，没有辅助就掉。

## 解读（推断，未验证）

- 通过的共同点：在地面上用双手推或转一个大件，接触多、姿态变化以绕竖直轴为主，辅助力撤掉前后差不多。
- 失败分三种：朝向跟不住（ep15、ep17，差距在朝向）；有辅助也学不会（ep19，快速长距离甩动）；依赖辅助（ep25，手内连续转动）。
- 可能有用、但都没试过的方向（排在发散排查之后，另写计划）：VOC 衰减更慢或在朝向误差大时暂停衰减；加大物体朝向的奖励权重；训练步数更长。
  这些都偏离官方配方，要登记；也不能拿 Tier 1 的这些结果去调 Tier 2 / 3。
