## 1. 做法

两条线同时跑，A 段约 22 小时，读完再定 B 段。

### A1：难集（ml40，buffer 1000 万，变体 A，原参考，seed 42）

段 `t1za`，8 条，约 19 小时。种子规则：同一参考、同一变体已经训过的才换种子；这 8 集在原参考上的 r3a 都没训过，所以都用 seed 42。
顺序按"一集就能动名次"排在前：ep25、ep4（修好任一集 MPPE 就能越过 Izus_systems 的 8.35 cm），再 ep10、ep28、ep11（MP 偏弱、SP 多已成功），然后 ep9、ep1，ep17 放最后（与 A2 的 r3o 臂对照）。
队列由 `make_var_queue.py t1za` 生成（10/29 加了 `t1za`、`t1zp` 两段，`arm_var_chain.sh` 加了两个前缀），训练挂 `v040_p185_nfg`，`V2D_WANDB_UPLOAD_CKPT=0`，按现有 Tier 1 链（冒烟、正式、4096 世界评测、导出一局）。support 列与各集现在交的基线 run 相同（ep4、10 关支撑面）。

### A2：朝向项（mf4090，buffer 400 万，r3o）

两段，先起 `t1zp_s43`（ep20 r3o seed 43，约 2.3 小时，基线 `t1-ep20-w2048-cap4m-r3a-s43-mf4090`，复现 ep20 seed 42 的升幅），再起 `t1zp`（等前一段结束，链最多等卡 6 小时，够用）：
- ep8 r3o seed 42（基线 `t1-ep8-w2048-cap4m-r3a-mf4090`，4096 世界 AUC 0.858）、ep21 r3o seed 42（基线同配方，AUC 0.556、MPPE 8.3 cm）：精度臂，同机同配方同种子。
- ep17 r3o seed 42（基线 `t1-ep17-w2048-cap4m-r3a-mf4090`）：ep17 是朝向先坏，正是朝向项针对的情形；按 A1 的换集规则判，不进精度臂的平均。
ep18 不用：它的基线偏弱（AUC 0.690、MPPE 8.9 cm）而导出那一局运气好，升幅读不清。r3o 由 `make_var_queue.py` 的 `variant: "r3o"` 写入队列（`V2D_OBJ_ORI_WEIGHT=1.0 V2D_OBJ_ORI_STD=0.4`，训练副本 `v040_p185_nfg_oo`）。冒烟要过 `plan-t3oo` 第 1 节的接线检查（日志有 `V2D object_orientation term: weight=1.0 std=0.4`，W&B 新项均值 ≥ 0.9），不过就停链。不再试收紧 σ（事实 8）。
A2 两段约 9 小时；mf4090 之后空出的时间留给 B 段（例如 ep25、ep4 的 400 万补种子），B 段另写。

## 2. 判据（登记）

### 每条 run 的健康（4096 世界，对 Tier 1 参考）
- 训练日志 DAY2_TRAIN_DONE、评测与导出各 1 份成功；不满足就记"坏 run"，不进任何比较。

### A1 换集规则（逐集，主看期望）
- 新 run 换掉清单里的现有 run，当且仅当下面任一条成立（都按 4096 世界）：
  (a) MP-SR 高出 ≥ 0.10，MPPE 不高出 1 cm 以上；
  (b) MP-SR 相差 < 0.10 而 SP-SR 高出 ≥ 0.10，MPPE 不高出 1 cm 以上；
  (c) 精度：AUC 高出 ≥ 0.03 且 MPPE 低 ≥ 0.5 cm，SP-SR、MP-SR 都不低 0.02 以上。
  几条同时有多个新 run 满足时，取 MP-SR 高的，再取 MPPE 低的。
- 每个 checkpoint 只导出一局（现行世界种子），不为了榜分重抽。导出那一局只用来报"这样打包榜上会是多少"，不用来选 run。

### A2 判据（精度臂 ep8、ep21、ep20 三条）
- **朝向项有效**：三条对各自基线的 4096 世界 ADD-AUC 升幅平均 ≥ 0.05，没有一条低于 −0.01；每条的 MPPE 不高出 0.3 cm 以上；SP-SR、MP-SR 都不低 0.02 以上。
- 只部分达到：记"信号"，B 段不铺开，只在 A1 修好的集上加 r3o 臂。

### B 段（A 段读完后写第 2 版再复核，不在这一版里起）
- A2 有效：把 r3o 铺到其余跟得住的集（两台分摊，ml40 上用 1000 万），按 A1 同一换集规则（精度条 c 就是为这一步写的）。
- A1 修好的难集（换集规则成立）再加一个种子核稳定性。

### 能不能拿第一（A 段读完就算，事先登记）
- 用 A 段的结果按换集规则拼出最好的清单，算它导出那一局的四项（即榜分）和 4096 世界的期望。
- 某个榜导出那一局超过表中门槛、且 4096 世界期望过下面的线：这个榜"可冲第一"，B 段优先给它。期望的线：SP-SR ≥ 29.5 / 30，MP-SR ≥ 28.5 / 30，MPPE < 2.78 cm（AUC 不设，事实 5）。
- 四个榜都差得远（难集修好不到 3 集，或 A2 无效）：如实报"Tier 1 第一在冻结前做不到"，B 段改为按名次和做，由 rxzhou 定。

### 提交条件（名次和这一档，10/29 定）
- 打包后导出那一局的四项就是榜分（事实 1）。至少一个 Tier 1 榜按 Kaggle 同分规则前进至少一名才交，`--only` 只交前进的榜。
- 清单 4096 世界的四项期望都不比 t1x1018 差（MP-SR、SP-SR 不低，MPPE 不高，AUC 不低）；差了就不交，免得留出数据上判时吃亏。
- 每次提交前按现有流程：jev 核结论（带对照）、`v2d_submit.py --dry-run`、rxzhou 同意。

## 3. 风险

- 每榜分开交（`--only`）时，四个榜可能挂不同时间的清单；最终每榜选 2 份时要逐榜核。
- mf4090 根盘 54 GB：起链前核盘，低于 25 GB 停链再说。
