### 2.1 r3o 的改法（只改训练副本，评测器不动）

- 新副本 `v040_p185_nfg_oo` = `v040_p185_nfg` + 一个补丁（`third_party/patches/` 下，注明上游 v0.4.0 与基于的副本）。评测与导出照旧用
  `fc_8c778f9`。观测不变，训出的 checkpoint 可以直接给评测器读。
- 新增第 13 项 `object_orientation`：θ = 仿真物体（与 `object_position` 同一个刚体）朝向与 `command.body_target_quat_w` 同一帧的测地角，
  奖励 exp(−θ²/σ²)。不计对称，与评测器一致。
- 配置加 `objective.object_orientation_weight`（默认 0）与 `objective.object_orientation_std`（默认 0.4）。课程各段没写这一项时用
  objective 里的权重。默认值下目标函数的输出与现在逐位相同。
- r3o 的取值：σ = 0.4 rad、权重 1.0，9 段相同；r3a 的两项照旧。取值的依据只有现有的 `palm_orientation`（σ 0.4、权重 1.0）、
  `object_position`（权重 1.0）与公开的 MP-SR 常数 30°：误差 5°、15°、30° 时奖励约 0.95、0.66、0.18。不用任何一档的结果调这两个数，
  只试这一个变体。
- 测试：已知四元数的项值（0、0.4 rad、π，以及 q 与 −q）；权重 0 时补丁前后目标函数在随机批上逐位相同；r3o 的配置展开后 9 段权重都是
  1.0、σ 0.4，其余 run 都是 0；`fc_config_check.sh` 意外键 0 个；`assert_cfg.py` 加 r3o 的规则（名字带 `-r3o-` 的必须是上面四个值，
  并且链的 `V2D_FC_SRC` 指向 `v040_p185_nfg_oo`）。
- 生成器：`make_var_queue.py` 加 `--variant r3o`（run 名 `-r3o-`，在 r3a 两项之后加两项覆盖），补测试；原有段重新生成必须逐字相同。

## 3. 判据（执行前登记，不改）

  - **有起色**：不是修好，且 SP-SR ≥ 0.3，或 MPPE 不超过现在交的那条 run 4096 世界 MPPE 的 0.7 倍。

  记“Tier 2 也是先丢朝向”，做 P2；否则不做 P2，写下结果另议。
