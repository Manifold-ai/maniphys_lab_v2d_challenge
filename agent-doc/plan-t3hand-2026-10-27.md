## 1. 优先级与做什么

### P1. 被拿段里参考朝向的跳变修复（物体一侧，dr2s 层之后、dyn7 之前）

机理：事实 3。做法只改朝向、只改被拿段里的"跳变段"，位置不动，没被碰的段不动。
1. **输入**：`tier3_cari4d_gb5_best_dr2s` 的世界位姿（`t3fx/runs/.../data/chunk-000/episode_*.parquet` 的 `observation.object.pose`）与它的物理检查 `held`（`t3fx/runs/physics/tier3_cari4d_gb5_best_dr2s/out/<集>.npz`，闭合 GAP = 5 同 dyn7）。先对称归一（与 dyn7 的 symmetry 步相同：逐帧取离上一帧最近的等价旋转），再找跳变。
2. **跳变段**：在每个被拿段里，相邻帧转角 > `JUMP_DEG` = 24°（dyn7 / 动力学检查的口径）的帧是跳变。从跳变前最后一个"好帧" a 起，找之后第一个帧 b，使 b 与 a 的转角 ≤ `JUMP_DEG` × (b − a)（按每帧 24° 的上限能转到的量）且 b 之后 `GOOD_RUN` = 5 帧内没有跳变；[a, b] 之间的帧用 a、b 两端的球面插值替换。
   找不到 b（跳过去就不回来，一直到段尾）：b 取段尾，同样插值——段尾由 dyn7 的 TAPER 接到锁定段，插值到段尾等于把跳变前的分支延续到段尾。
3. **上限**：一集里被替换的帧数 ≤ 20%；插值后每帧转角 ≤ `JUMP_DEG`。超了这一集不改、记原因。
4. **输出**：新版本 `tier3_cari4d_gb5_best_dr2s_hr`（同 dr2s 的目录结构，只换 `observation.object.pose` 的四元数，其余列逐字节相同），全部 30 集都跑（没有跳变的集逐字节相同），`runs/<version>.held_fix.json` 记每集替换了哪些段。
5. **下游**（我们自己的副本 `t3recon/t3fx`，`t3r_level1.sh` 从 dyn7 步起的同一条链）：物理检查 → dyn7 → 物理检查 → mkroot、重定向、usda（`t3r_level1_usda.sh` 的步骤，集名另起）→ 训练用的 motion parquet。
6. **检查（H0，逐集，不过就退回 gb5）**：（a）交付层轮廓 IoU 中位不降超过 0.01（`t3_frame_confidence.silhouette`，与 `plan-t3fix` G1(a) 同）；（b）相邻帧转角 > 24° 的帧数不增加，被拿段里为 0；（c）动力学违规帧不增加；（d）没改的帧逐字节相同；（e）`check_inputs.py` 过；（f）dyn7 的 MAX_OFFSET 断言过（输入已连续，不该触发）。
7. **训练与判（H1）**：ep13、19（mf4090）与 ep27（ml40）各一集，seed 42、与 gb5 同配方；R1（4096 世界、对自己参考 SP-SR ≥ 0.5 且 MPPE ≤ 10 cm）过记"换"；不过只记数字，并报导出那一局物体丢的帧比原 run 晚多少（`rollout_object_error.py`）。
   ep13 另有 B1 查出的翻转（P2）：P1 只修跳变不改分支；若 R1 不过而丢的帧明显后移，再看 P2。

## 3. 风险

- 跳变的两端也可能都在错的分支上，插值只保证连续，不保证对；轮廓 IoU 对对称物体看不出分支。所以 H0(a) 只防变差，不证明变好。
- 篮子、零食盒都是 `t3_symmetry` 认成对称的物体（各一个 180°），对称归一后仍有跳变说明是非对称的翻转或跟丢，插值跨过的帧越多越不可靠；20% 上限为此设。
- 只改 3 集，对榜最多多 3 集；全成也够不上第 1 节（事实 7）。
