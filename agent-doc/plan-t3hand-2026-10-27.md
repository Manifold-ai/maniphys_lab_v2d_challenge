## 1. 优先级与做什么

### P0. 对照臂：参考不变，只关掉朝向终止（配置改动，不重建）

- 用 gb5 的参考训 ep13（mf4090，段 `t3pcoff`）与 ep15（ml40，段 `t3qcoff`），变体 A 只把 `termination.object_orientation_threshold` 从 0.6 改成 3.2 rad（> π，等于关掉；复核指出 1.5 rad = 86° 挡不住 100–171° 的跳变），顶层与 env 都改，seed 42，run 名带 `-ocoff-`；
  队列由 `t3pg5c_s43`、`t3qf1` 的行手工派生（`stages/policy/queues/{mf4090_t3pcoff,ml40_t3qcoff}*`，正式队列的 W&B 标签改成段名、冒烟的仍是 smoke），`arm_var_chain.sh` 对队列里一致的朝向终止值做正向断言。每台一条，约 3 小时。
  ep15 是最干净的对照（一个 168° 跳变正落在丢的第 498 帧）；ep13 是 P1 的主目标。ep27 的误差比第一个跳变早 4–8 帧，不作对照。
- **C1**：基线是同集 seed 42 的 gb5 原 run（ep13：`t3-ep13-w2048-cap4m-r3a-gb5-mf4090`，段 t3pg5b；ep15：`t3-ep15-w2048-cap10m-r3a-gb5-ml40`，段 t3qf1）与 ep13 的 seed 43（t3pg5c_s43）。"丢的帧" = `rollout_object_error.py` 里误差首次 > 20 cm 的帧（原 run：ep13 第 191 帧、ep15 第 531 帧）。
  R1 过（4096 世界、对自己参考 SP-SR ≥ 0.5 且 MPPE ≤ 10 cm）→ 终止就是机理，这套配置本身成为候选（但导出那一局的朝向误差也要小，见第 3 节风险）；
  R1 不过而丢的帧比两条基线都晚 ≥ 60 帧 → 终止是起因之一；都不是 → 记"不确定"（每集只有一个 seed），不改 P1 的排期。
- 它与 P1 并行：P0 先起（卡空着），P1 的 H0 一过、哪台空就先起 P1。

### P1. 空闲段里参考朝向跳变的去除（物体一侧，dr2s 层之后、dyn7 之前）

机理：事实 2、4。只改朝向，质心路径不动，dyn7 锁定的歇着段不动。工具 `stages/recovery/tier3/t3_held_fix.py`（`track2/t3sil-choose`）。
1. **输入**：`tier3_cari4d_gb5_best_dr2s` 的世界位姿与它的物理检查 `held`（闭合 GAP = 5）、`depth_post.json` 的歇着锚点——与 dyn7 读法相同；锁定 = 没被拿且在锚点里，其余帧是"空闲段"（被拿或空中）。先对称归一（dyn7 的 symmetry 步）。
2. **去跳变**：空闲段内按相邻帧的测得转动重建朝向，转角 > `JUMP_DEG` = 24° 的那一步视为分支切换、增量置零（之后测得的相对运动照旧保留）。
3. **接端**：重建到段尾与测得的段尾差一个转动 D；把 D 按余弦权重（段首 0 → 段尾 1）匀到整段，两端都接上邻段，每帧只多出 angle(D) / 段长的转速。段在集尾（没有后邻）时 D = 0。
4. **上限**：angle(D) / 段长 > `MAX_SPREAD_DEG` = 3°/帧的段不改、记"跳过"；处理过的段里仍有 > 24° 的帧，这一集整集不改、记原因。
5. **输出**：`tier3_cari4d_gb5_best_dr2s_hr`（同 dr2s 的目录结构，只换 `observation.object.pose`；只被对称归一转过的帧保留输入字节），`depth_post.json` 照抄到新名（位置与锚点没变），`held_fix.json`、`provenance.json`。全部 30 集都跑。
6. **下游**（我们自己的副本 `t3recon/t3fx`，照 `t3r_level1.sh` 的 physics / dyn7 步与 `t3r_level1_usda.sh` 的 mkroot / 重定向 / usda 步，集名另起）：物理检查 → dyn7 → 物理检查 → 重定向 → motion parquet。
7. **检查（H0，逐集，不过就退回 gb5）**：（a）改过的帧上交付层轮廓 IoU 中位不降超过 0.01（`t3_held_check.py`；对对称物体这只防变差，分不出分支）；（b）处理过的段里相邻帧转角 > 24° 的帧为 0，并在 dyn7 输出与 motion parquet 上再量一次；（c）动力学违规帧不增加；（d）没改的帧逐字节相同（`t3_held_check.py`）；（e）`check_inputs.py` 过。
   没做、记为风险：用重建的人手腕朝向判跳变两侧哪一支对（Tier 3 自己就能做，这一轮来不及）。
8. **训练与判（H1）**：ep13、19（mf4090，段 `t3phr`）与 ep15、27（ml40，段 `t3qhr`），seed 42、变体 A 不变（朝向终止 0.6）；R1 过记"换"（暂定：对自己参考过了判断不了分支选得对不对）；不过只记数字，并报丢的帧比原 run 晚多少。
   选这 4 集只靠事实 3–4（只用 Tier 3 的数据）：导出那一局丢的帧与空闲段跳变帧重合或只差几帧。

## 3. 风险

- 去掉跳变增量等于认定跳变前的分支对；跳变后那一支才对的集，修完仍错，H0(a) 对对称物体看不出来。
- 段末残差匀到整段，是把"两个歇着段之间物体真转了 D"当成缓慢转动；D 大、段短的集按上限跳过。
- 放宽朝向终止训出的策略可能只跟位置、朝向乱转；它只作对照，不作候选，除非 R1 过且导出那一局的朝向误差也小。
- 只改 4 集，全成也够不上第 1 节（事实 8）。
