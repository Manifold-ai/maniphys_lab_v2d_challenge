# 计划：关掉朝向终止的两集加物体朝向奖励项（t3oo，10/28，第 1.1 版）

2026-10-28 08:0x MDT 写定第 1 版，起因是 rxzhou 的指示"试试奖励里加朝向项"；第 1.1 版（10:0x MDT）按独立复核改。分支 track2/p1-training。判据在结果出来之前登记。只改训练配置与训练副本，参考不变（gb5）；只用 Tier 3 的参考与对自己参考的读数。这一轮不提交。

## 0. 事实

1. `plan-t3ocoff` 与 `plan-t3hand` P0 的结论：变体 A 只把 `termination.object_orientation_threshold` 从 0.6 改成 3.2 rad（关掉），ep15、ep27 导出那一局的位置全程跟住（ep15 715 帧最大 5.6 cm、首次 > 10 cm 为 None；ep27 565 帧最大 8.4 cm），但朝向没有任何约束：奖励里没有朝向项，终止是唯一约束朝向的东西（`plan-t3hand` 事实 2）。读数（`results/ml40/t3hand/o2_ep15.txt`、`results/t3hand/o2_ep15_post.txt`、`results/t3hand/o2_ep27_ocoff.txt`、`o2_ep27_post.txt`）：
   - 翻转之前那段对自己参考的朝向误差均值：ep15 第 0–497 帧 0.414 rad（gb5 基线 run 同段 0.278）；ep27 第 0–181 帧 0.127 rad（基线 0.109）。关掉终止后朝向变松（ep27 只差 0.018 rad，一局之内分不出）。
   - 翻转之后（两集不一样）：ep27 第 476 帧后 2.20 rad（约 126°），仿真里的篮子保持翻转前那一支；**ep15 第 503–715 帧 0.905 rad、中位 0.717**（基线 run 那时已丢，1.738 rad 没有意义），即仿真里的牌子既没有停在翻转前那一支（那样该是约 2.9 rad），也没有跟上参考，介于两者之间。4096 世界：ep15 对自己参考的 SP-SR 0.002、朝向误差均值 33.5°；ep27 SP-SR 0。
   - 4096 世界位置：ep15 MPPE 3.32 cm、CHORD_SR 0.96；ep27 MPPE 17.1 cm、CHORD_SR 0.73（物体终止 17%、手掌终止 26%）。
2. 物体朝向奖励项已有实现（`plan-r3o-2026-10-15.md` 2.1）：训练副本 `v040_p185_nfg_oo` 比 `v040_p185_nfg` 多一个补丁，第 13 项 `object_orientation` = exp(−θ²/σ²)，θ 是物体刚体与参考四元数的测地角（与终止、评测器同一套量法，不计对称）；开关走环境变量 `V2D_OBJ_ORI_WEIGHT`（权重）、`V2D_OBJ_ORI_STD`（σ，补丁默认 0.4）；checkpoint 存的配置与课程保持上游 12 项，评测器 `fc_8c778f9` 照样能读（10/15 的 G1 门：4096 世界评测与 1 局导出都成功）。`fc_run.sh` 有守卫：run 名带 `-r3o-`、设了权重、副本打了补丁三样要同时具备。两台的副本按清单核对 `FC_SRC_OK`（`results/t3oo/fc_src_oo_{mf4090,ml40}.txt`）。10/15 的试点只用过 σ 0.4，等于补丁默认值，所以 `V2D_OBJ_ORI_STD` 真能转进容器这件事还没有被任何一条 run 证明过。
3. 10/15–16 的 r3o 试点（σ 0.4、权重 1.0、终止 0.6 仍开）在 Tier 1 的 7 集与 Tier 2 的 8 集跟丢集上判"没用"（修好 0、有起色 0）。那批集按 MP-SR 的尺度先丢的是位置；终止开着时新项只在 0–34° 起作用，与终止重叠。本计划的情形不同：ep15、ep27 位置已经跟住，缺的正是朝向约束。
4. σ 的作用范围：奖励 exp(−θ²/σ²)，梯度 ∝ θ·exp(−θ²/σ²)/σ²。σ 0.4：误差 15° / 30° / 60° 的奖励约 0.65 / 0.18 / 0.001，只在翻转前那段提供梯度，在 ep15 翻转后的 0.9 rad 与 ep27 的 2.2 rad 处都没有梯度。σ 1.0：0.9 rad 处奖励 0.44、梯度仍可观，2.2 rad 处约 0.008；σ 2.0：2.2 rad 处奖励 0.30、梯度可观，但 30° 以内几乎不区分（0.93 以上）。所以臂 2 的 σ 按每集翻转后的实际误差选：ep15 用 1.0，ep27 用 2.0。
5. 翻转后哪一支对真值，量不出来（`plan-t3ocoff` 事实 3）：ep15 去跳变时翻转前那一支延续到段尾与放下后歇着的位姿差 119°（牌子无对称），即歇着段的重建支持一次真实的大转动；ep27 的篮子绕主轴 2 翻 180° 是对称元（`plan-t3flip13`），翻转 171° + 100° 不是纯对称翻转，很可能是重建的假象。所以"追上翻转后那一支"对榜上的 SP-SR 是好是坏不知道，臂 2 不是通往榜单的路，它是能力探针（见第 1 节）。
6. 两台卡 05:3x MDT 起都空着（`plan-gpu-idle` 10/28 05:3x）。ep15 在 ml40（buffer 1000 万）一条约 2.7 小时训评导出，ep27 在 mf4090（400 万）一条约 2.5 小时。

## 1. 做什么

- 段 `t3pr3o`（mf4090）：ep27 两条 run；段 `t3qr3o`（ml40）：ep15 两条 run。都是 gb5 参考、变体 A、终止 3.2 rad、seed 42，训练副本 `v040_p185_nfg_oo`，`V2D_OBJ_ORI_WEIGHT=1.0`，两臂：
  - **臂 1，σ 0.4**（run 名 `-r3o-gb5-ocoff-sg04-`）：问题是"关掉终止后能不能靠奖励把翻转前的朝向收回来"。预期：翻转前朝向误差回到基线水平或更好，位置不变差；翻转后仍停在翻转前那一支（ep27）或维持原样（ep15）。有判断力的主要是 ep15（ocoff 与基线差 0.136 rad）；ep27 的 ocoff 与基线只差 0.018 rad，分辨不出，O2′ 登记容差。
  - **臂 2，ep15 σ 1.0、ep27 σ 2.0**（`-sg10-` / `-sg20-`）：问题是"给翻转后那一支梯度，策略会不会在手里把物体转过去"。这是能力探针，不是通往榜单的路（事实 5）：它回答的是"关终止、放宽 σ 之后策略能不能在手里转动物体"，结论可以作为想法（不是数据）用于 Tier 1 / 2 跟丢集里物体相对掌心朝向漂移中位 102.5° 的问题（`plan-r3o` 执行记录末尾）；对 Tier 3 它不进候选，除非过 R1 且另有办法判翻转后那一支对真值。
  - 队列由 `mf4090_t3pocoff`（ep27）与 `ml40_t3qcoff`（ep15）的行手工派生，只多两个环境变量、run 名 `-r3a-` → `-r3o-` 并加 `-sgDD-`；冒烟行同样带两个变量。
- 代码改动（契约 → 代码 → 测试）：`docs/contracts/policy.md` POLICY-I010 改成"σ 每行自带、与 run 名 `-sgDD-` 一致"；`arm_var_chain.sh` 加 `t3pr3o*`、`t3qr3o*` 两段（挂 oo 副本，排在 `t3p*`、`t3q*` 之前；段名避开 `t3po*` 这种会吃掉 `t3pocoff` 的前缀），r3o 行的核对挪到 `stages/policy/r3o_lines.awk`（权重 1.0、σ 与标签一致、不带标签时 0.4、σ 不许 0、两个变量各正好一次、普通副本的段一行都不许带），测试 `stages/policy/test_r3o_lines.sh`（`results/t3oo/test_r3o_lines.txt`：R3O_LINES_OK，含仓库里 7 个真实队列）；队列、冒烟、期望表、导出清单各两份。不改补丁、不改评测器。
- 冒烟过关条件（在链本身的条件之上）：每条冒烟的训练日志里有 `V2D object_orientation term: weight=1.0 std=<σ>`，σ 与 run 名标签一致（这是 `V2D_OBJ_ORI_STD` 转进容器的第一次证明）；`fc_run.sh` 的运行记录里 `obj_ori_std=<σ>`；W&B 摘要里新项均值 ≥ 0.9（`plan-r3o` 2.1 的接线检查；σ 1.0、2.0 的臂这一条几乎必然满足，只对 σ 0.4 有分辨力）。不满足就停链，查接线。
- 判（每条 run，4096 世界与导出那一局，对自己参考；读数工具 `t3g5_readout.sh`、`rollout_object_error.py --ori-range`、`train_term_table.py`）：
  - **R1**：SP-SR ≥ 0.5 且 MPPE ≤ 10 cm → 记"换（暂定）"，进下一版清单的候选；进候选不等于交。
  - **O1（位置）**：导出那一局最大误差 ≤ 20 cm（首次 > 20 cm 的帧为 None）且 4096 世界 MPPE ≤ 10 cm → "位置跟上"；与 ocoff 臂并列（ep15 3.32 cm，ep27 17.1 cm）。
  - **O2′（翻转前的朝向，只判臂 1；臂 2 只报）**：翻转前那段（ep15 第 0–497 帧、ep27 第 0–181 帧）朝向误差均值 ≤ 0.5 rad 且不高于同集 gb5 基线（ep15 0.278、ep27 0.109）→ "朝向项把翻转前收紧了"；与基线之差在 ±0.02 rad 以内记"分不出"；另与 ocoff 臂（0.414、0.127）并列。
  - **O3（翻转后，只报）**：翻转后那段（ep15 第 503–715 帧、ep27 第 476–565 帧）朝向误差均值，对照 ocoff 臂（ep15 0.905、ep27 2.20）；< 0.5 rad 记"追上了翻转后那一支"，否则记数字。它不说明哪一支是真值。
  - **只报**：`train_term_table` 的各类终止比例与回合平均进度，W&B 里新项的均值。σ 大的臂在大部分误差范围内奖励都在 0.5–0.93，接近每步一个常数的"存活奖励"，会改变策略躲位置终止、手掌终止的动机，所以臂 2 在 O1 上与 ocoff 的差别不能直接归到朝向梯度上。
- 结果怎么用（与 `plan-t3ocoff` 的规则统一）：
  - 任一 run 过 R1 → 进候选，交不交按策略第 1 节、要 rxzhou 同意，并且要先解决"翻转后那一支对不对真值"的问题（事实 5），不能单凭对自己参考的 SP-SR 交。
  - 臂 1 过 O1 与 O2′、不过 R1 → 进下一版清单的候选，身份是 Tier 3 MPPE 维度的替换材料（位置跟住、朝向比 ocoff 臂紧）；ocoff 臂本身按 `t3ocoff` 的规则不是候选。是否进清单按清单计划另定。
  - 臂 1 过 O1、不过 O2′ → 与 ocoff 臂同一类，不进候选，记数字。
  - 臂 1 不过 O1 → 朝向项让位置变差，记录；两集都如此则停这个方向。
  - 臂 2：只报 O1、O3 与终止比例，写成"能力探针"的结论。
- 不做：ep13（新参考在放下后被参考里无手接触的物体移动卡住，与朝向无关）、ep19（87 个跳变帧，关终止无效）。不提交。不用人工看图的结果做选择或调参。

## 3. 风险

- 朝向项不计对称（与评测器一致）：ep27 篮子绕主轴 2 翻 180° 几何上等价，奖励却按 180° 算，策略可能为了对齐一个看不出区别的朝向多花力气；这与榜上的评分一致，不改。
- 奖励归一化：第 13 项加进求和，10/15 的 G1 已验证评测器兼容，但当时终止 0.6；本计划终止 3.2 是普通配置覆盖（ocoff 两段已证明可训、可评、可导），两者正交，没有联合验证过。冒烟（第 1 段 409.6 万步）就是联合的第一道检查。
- σ 1.0、2.0 没有在任何集上跑过；它们翻转前几乎不区分小误差，臂 2 翻转前的朝向可能比 ocoff 臂更松，这是设计上接受的，O2′ 对臂 2 只报。存活奖励的混杂见第 1 节"只报"。
