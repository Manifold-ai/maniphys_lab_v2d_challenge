## 1. 想法与理由

被手攥着的刚体，在手掌系里的位姿基本不变。手杖的物体重建在换手之后坏了，但同一段的手掌重建是平滑的；所以被拿段里手杖的位姿用"这只手掌的位姿 × 一个固定的握持变换"来给。
复核的只读探针（第 2 版改动 B2）表明：手掌系里**长轴的方向**与**握点**（手掌在手杖上的位置）在各块之间一致，变来变去的只有**绕长轴的自转**——视频里看不出的那个自由度（事实 5），也是 88 个跳变里 36 个所在的轴。所以挂到手上的是长轴方向与握点（数据支持的部分）；自转取手掌系里最大的一簇彼此一致的帧（不是全体的 medoid），这是"握住后手杖不在手里自转"的先验，量不出真假，作为未核实项报出。
这是物理先验，只用 Tier 3 自己的人体与物体估计，不需要判哪一支对。与去跳变不同：不假设"两次跳变之间的运动是真的"，运动全部来自手。

## 2. 做什么

### 第 0 步：验证（只用 CPU，只报，过了闸门才做第 1 步）

1. **坐标对上**：gb5 参考 parquet 由 **dyn7 层**生成（Tier 3 根 `root_gb5` 的 ep19 parquet 与 `t3fx/runs/tier3_cari4d_gb5_best_dr2s_dyn7/` 的同一文件 sha256 相同，复核核过）。在 dyn7 层的物体位姿与 parquet 的 `object_body_*` 之间拟一个刚体变换，残差位置 ≤ 1 mm、朝向 ≤ 0.1°才认定；dr2s 与 dyn7 同一世界系，同一个变换把手掌位姿换到 dr2s 层。不过就停。
2. **分阶段按手掌到表面的距离**：每只手掌到手杖网格表面的最近距离（cKDTree，同 `t3_physics_check.py` 的量法，逐手分开）；一只手 ≤ 15 cm 的帧算它握着。右手阶段 = 右手握着而左手没有的帧，左手阶段同理，两只都握着的连续区间是换手窗口（复核量得约 391–451 帧；另有 241–253 帧两只都近，按距离近的那只算、不当换手）。不用接触标记、不用到原点的距离。
3. **好帧**：这一帧与前后各一帧物体单帧转角都 ≤ 12°。每个阶段在好帧上算手掌系里的长轴方向 d_t = P_tᵀ(O_t a)、握点 g_t = O_tᵀ(p_palm − o_t) 沿长轴的分量 s 与离轴距离 r、完整的相对朝向 X_t。
4. **闸门 G0（第 2 版）**：每个阶段好帧 ≥ 60 帧；好帧上 d_t 对其弦均值的夹角中位 ≤ 15°；把好帧按 30 帧分块，各块 s 中位的极差与 r 中位的极差都 ≤ 10 cm。不过说明握持不刚性，停，记"不确定"。
5. **自转的取法**：每个阶段在好帧里找最大的一簇——X_t 两两夹角都 ≤ 10°（以每个好帧为中心数 10° 内的好帧，取最多的那个中心，簇 = 它 10° 内的帧）；X̂ = 簇的弦均值，再把 X̂ 的长轴方向与握点换成第 3 条的弦均值 / 中位（只留簇的自转）。只报：簇的大小与位置、各块的自转对 X̂ 的偏差（这是未核实的不确定度）。

## 4. 风险

- **自转是先验，不是测量**：挂上去的自转来自手掌系里最大的一簇，"握住后不在手里自转"量不出真假；指标认自转，若真值里手杖在手里转了，SP-SR 的朝向均值会吃亏。
- **手掌估计偏**：G1 手掌来自人体重建的重定向（`soma_to_g1.py` 只拿物体做接触标记，`ee_pose_w` 不依赖物体轨迹，复核核过，没有循环依赖），挥动时人手的估计也可能偏；手掌平滑不等于准。
- **dyn7 会再改**：挂上的帧过 dyn7 还会被窗口均值、抬地面等改动（gb5 上被拿段朝向最多改 12.7°、位置 p95 8 cm），H0 在 dyn7 之后量。
- **MP-SR 拿不到**：Tier 1 的 ep19 MP-SR 也只有 0.26；这一集的价值在 SP-SR、MPPE、AUC。
- **对榜**：ep19 若过 R1 并上榜成功，Tier 3 SP-SR 多一集；够不够策略第 1 节按当时的榜与 ep15、ep27 的结果重判。
