## Practical notes / gotchas

1. **The triple match is smaller than it looks.** Most "hand control" in this literature means the *policy tracks 3D wrist/hand keypoints* (OmniH2O, HOVER, CLONE, TWIST), not finger actuation. Genuine finger/dexterous-hand control in released code is limited to: **HoloMotion** (7 hand SKUs, one shared policy), **Humanoid-GPT** (BrainCo variant), **HOMIE/OpenHomie + OpenWBC + TrajBooster + EgoHumanoid** (all Dex3 via the same `avp_teleoperate`/HOMIE lineage, mostly binary open/close), and **OmniClone** (Inspire, binary).
2. **Licenses will bite you.** Non-commercial: **H2O/OmniH2O, HOMIE, PBHC/KungfuBot(2), CLOT, CLONE, BFM-Zero, UFO** (CC-BY-NC or CC-BY-NC-SA). Permissive and safe: **ASAP, FALCON, TWIST, TWIST2, BeyondMimic, SkillBlender, InternHumanoid, VideoMimic, PhyGile** (MIT); **HOVER, GMT, MOSAIC, HoloMotion, Humanoid-GPT, OpenTrack, ResMimic, holosoma, FRoM-W1, EgoHumanoid** (Apache-2.0). **No LICENSE file at all** (⇒ default all-rights-reserved, not "free"): HDMI, ScaleBFM, HumanoidArena, mimic-lite, GRIT, GentleHumanoid, OpenWBC, OpenTrajBooster, UH-1, HumanPlus, CHILD.
3. **G1 DoF conventions differ and matter.** `g1_29dof_anneal_23dof` (ASAP) = 29-DoF URDF with 6 wrist joints frozen. `g1_23dof_lock_wrist` (CLOT) = same idea. `g1_29dof_waist_fakehand` (FALCON) = 29 + massless hand proxies. BeyondMimic/HoloMotion/BFM-Zero/holosoma/HuMiT are true 29. A ckpt is **not** portable across these — obs/action dims differ (UFO's README says this explicitly).
4. **Sim backend has shifted.** 2024 → Isaac Gym Preview 4 (H2O, ExBody, HumanPlus, UH-1). 2025 → Isaac Lab (HOVER, BeyondMimic, HDMI, SONIC). 2026 → **mjlab / MuJoCo-Warp / MJX** (CLOT, UFO, BFM-Zero, mimic-lite, OpenTrack, Humanoid-GPT). **Genesis** appears only in ASAP (via HumanoidVerse). **Newton** appears only in NVIDIA's soma-retargeter and a couple of hobby repos — no production tracking system runs on it yet.
5. **Most actively maintained right now** (last commit within ~6 weeks): amazon-far/holosoma (09-04), EGalahad/mimic-lite (09-09), OpenRobotLab/OpenHomie (09-08), mrzuang/GRIT (09-02), HybridRobotics/motion_tracking_controller (08-18), HoloMotion (08-19), Humanoid-GPT (08-20). **Effectively dead:** human2humanoid (H2O/OmniH2O, 2025-02), humanplus (2024-07), expressive-humanoid (2025-03), NVlabs/HOVER (2025-07).
6. **Two of your listed names resolve to something different than expected:** "Retargeting Matters" *is* GMR (has code); "MHC" is a Digit V3 system, not Unitree. And **Athena-WBC is withdrawn.**
