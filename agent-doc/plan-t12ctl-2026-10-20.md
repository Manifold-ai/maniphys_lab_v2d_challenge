# 计划：零残差回放的成功集对照（t12ctl，10/20 晚，第 1 版）

2026-10-20 19:0x MDT 写定第 1 版，分支 track2/p1-training。起因：t12replay 与 t12ref 只回放过失败集（ep1、ep4、ep25），没有成功集的对照；
“回放在接触前摔”能不能说明“训练拿不下这一集”，要先看成功集的回放摔不摔。判据在结果出来之前登记在这里。只用 Tier 2；不训、不提交。

## 0. 事实（都有记录）

1. ep4 零残差回放 1024/1024 在接触（第 133 帧）前摔，摔倒帧 88/88/89（`results/ml40/t12replay/mech_*ep4*_s409600.txt`）；限腰四版也都 100% 在接触前摔，最多推迟 9 帧
   （`results/ml40/t12ref/mech_*`，见 `agent-doc/plan-t12ref-2026-10-20.md` 执行记录）。
2. 回放里骨盆从第 20 帧起落在参考后面，第 60 帧落后 0.14 m（`results/ml40/t12ref/split_ep4_orig.txt`）。
3. 接触前的速度、偏航角速度、向心加速度 v·|ω| 都分不开摔与不摔：ep21（5.64 m/s²，MP-SR 0.965）、ep16（4.75，0.938）、ep15（3.31，0.987）都比 ep4（1.98）猛
   （`results/ml40/t12ref/turn_load_tier2_ml40.txt`、`results/t2dg/ref_root_speed_tier2_mf4090.txt`、`results/t2dg/hand_join_b1014.txt`）。
4. 换参考做别集的零残差回放可行：ep4 checkpoint `smoke-t2-ep4-w2048-cap4m-r3a-sd-mf4090/policy_409600` 的残差均值头为 0（`results/t12replay/residual_head_mf4090.txt`），
   动作只取决于 SONIC 照参考的输出；评测器的步数取自参考 parquet 本身（`harness.py` 421–423 行 `setup.reference.num_frames`），不取 checkpoint 配置里的值；
   `diag_rollout.py --parquet` 已核对评测 JSON 里的 parquet 必须是新参考（t12ref 四次都过）。物体换了（球棒 → 别的物体），网络的观测维度若不同会直接报错，不会静默。

## 1. 做什么

ml40（GPU，用前等卡空，挂 fc_8c778f9，`V2D_GPU=1`）：`stages/evaluate/t12ctl_chain.sh` 用上面那个 checkpoint 对四集成功集的原参考（`runs/motion/tier2`）各跑
`diag_rollout.py --worlds 1024 --palms --bodies --parquet …` → `diag2_sync.py` → `fall_mechanism.py --before <该集第一次接触帧>`：
ep16（t_c 109）、ep21（95）、ep15（126）：接触前 v·|ω| 最猛的三集成功集；ep0（t_c 203，MP-SR 0.986，v·|ω| 1.04）：走得慢的成功集。约 15 分钟。
另以 tag ep4 跑一次 ep4 原参考（加 --parquet 指向原参考；不加的结果已有），核对两条路径一致：摔倒帧分位相差 ≤ 2 帧。

## 2. 判据（登记）

- C0：每集 G0 过（照 t12fall 门槛）、同步闸过、评测 JSON 的 parquet 核对过；ep4 两条路径一致。不过的那一集不判。
- C1（回放会摔不是失败集特有的）：过了 C0 的成功集里，≥ 2 集“接触前摔倒”的世界 ≥ 50%。成立就把 R1 的读法降级：零残差回放摔不摔不能代表训练能不能拿下；
  t12ref 那类“先用回放筛参考”的做法作废，改参考的效果只能靠训练量。
- C2（回放会摔是失败集特有的）：过了 C0 的成功集全部“接触前摔倒”≤ 20%。成立就保留 R1：ep4 的走路段有现有统计量抓不到的东西，下一步查看器逐帧看（要用户看）或另找量。
- 介于两者之间记“混合”，逐集报，不下结论。
- 不按榜上分数挑东西；这一轮不提交（`agent-doc/strategy-2026-10-19.md` 第 1 节）。

## 3. 风险

- 成功集的参考换了物体，物体在仿真里被碰的方式不同；回放的动作只跟参考有关，但摔不摔会受物体影响（接触后）。所以只看接触前。
- checkpoint 配置里其余按集设定的值（如 reference.num_frames）不跟着换；残差为 0 时它们不进动作，只可能进观测，影响不到回放。
