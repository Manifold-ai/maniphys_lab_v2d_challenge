## 2. 判据（登记）

- **健康**：冒烟通过；4096 世界 `non_finite_worlds` 为空；导出 EXPORT_OK。不健康的 run 不判、不重跑。
- **换集**（逐集，4096 世界，对 Tier 2 自己的参考；对照是第 0 节第 3 条的 run）：同时满足才换——ADD-AUC 比对照高 ≥ 0.03；MP-SR、SP-SR 不低于对照 − 0.02；MPPE 不比对照高 0.5 cm 以上。
- **打包与上传**：底是当时榜上 AUC 那份（现在是 t2a1102；`t2auc2` 后两集若先换进新包，就以那份为底），换入满足条件的集，`tools/t2_swap_totals.py` 算两个数：导出那一局 AUC 平均 ≥ 底 +0.010，并且 4096 世界 ≥ 底 +0.005。
  另加一条按第 0 节第 2 条折算的条件：底的榜分 + 0.21 × 导出那一局的 AUC 平均变化，要比当时榜上的下一名高 ≥ 0.002。三条都满足才问 rxzhou；只交 AUC 一个榜（`--only`）。问时写明折算比例只来自一对读数。
- 读数不改判据；读法另写，标明是解释。
