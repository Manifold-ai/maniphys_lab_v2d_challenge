## 1. 做什么

从第 3 条的两个起点各续训 70000640 步（总步数 419999744，能被 2048 整除），每个起点两个分支，共 4 条 run：

- **F（贴近评测）**：最后一段的 `immediate_first_frame_probability` 改成 1.0，所有重置都从第 0 帧起跑、不冻结。终止照起点（ot3，物体 0.3 m）。
- **K（对照）**：课程不改（最后一段 0.5），只多训同样的步数。F 与 K 之差才归到“起跑方式”；K 与起点之差是“续训本身”（空 replay、多训）的效应。

两个分支都加 `training.resume=true`、`training.checkpoint_path=/repo/runs/flash_chord/<起点>/state_349999104.safetensors`、`training.optimization.learning_rate_schedule_updates=683592`；F 另加 `curriculum.stages.8.immediate_first_frame_probability=1.0`（只写顶层，第 0 节第 5 条）。
其余 Hydra 覆盖与起点的队列行逐项相同（`stages/policy/queues/mf4090_t2mtr.txt`）；行首环境变量 `V2D_WANDB_TAG=t2ft V2D_MAX_RETRY=0 V2D_GPU_APPS=1 V2D_WANDB_UPLOAD_CKPT=0 V2D_KEEP_STATES=1`（tag 换成 t2ft，其余同起点）。
run 名 `t2-ep{25,4}-w2048-cap4m-r3a-ot3-ft{f,k}-mf4090`，顺序 ep25 F、ep25 K、ep4 F、ep4 K；队列 `stages/policy/queues/mf4090_t2ft{,_smoke}.txt`（手写，头部注明计划）。

## 2. 判据（登记）

- **M（覆盖生效）**：起链前的配方断言全过（含学习率调度长度）；每条 run 日志第一行进度的起始步数是 349999104；W&B 汇总课程段 8，F 的 `immediate_first_frame_probability` 为 1.0、K 为 0.5。M 不过的 run 不判下面各条。
- 只比最终 checkpoint（第 419999744 步），4096 世界、对自己参考。门槛沿用 t2mtr：同一 run 内 checkpoint 之间就差 23 cm（ep25），所以降 ≥ 23 cm 记“成立”，10–23 cm 只记信号。
- **K0（先读续训本身）**：K 与起点的 MPPE 差在 10 cm 以内、ADD-AUC 不低于起点 − 0.02，记“续训本身无害”，F 按下面各条对起点判。K 比起点高 ≥ 10 cm 或 ADD-AUC 低 ≥ 0.02，记“续训本身有害”，F1、F3 改为对 K 判，F 的降不归到起跑方式。K 比起点低 ≥ 10 cm，记“多训有用”，照样往下判。
- **F1（续训微调有用）**：F 的 MPPE 比参照（起点，或按 K0 换成 K）低 ≥ 23 cm，且 ADD-AUC 不低于参照 − 0.01。对起点：ep25 ≤ 80.43 cm、≥ 0.108；ep4 ≤ 98.48 cm、≥ 0.100。
- **F2（归到起跑方式）**：F1 成立，且 F 比同集 K 低 ≥ 10 cm、ADD-AUC 不低于 K − 0.01。F1 成立而 F2 不成立，记“多训有用，起跑方式没分出来”。
- **F3（有害）**：K0 记“无害”而 F 比起点高 ≥ 10 cm 或 ADD-AUC 低 ≥ 0.02，记“只从第 0 帧起跑有害”（多半是忘了后段的参考），不往下推。
- 两集都按上面判，单个种子；成立也只记“有信号”，要换进清单先在同一集上重复一次。成立的那集再与现在交的清单比（ep25 117.09 cm），换不换照策略第 1 节两张榜一起算。
- SP-SR、MP-SR、骨盆失败比例、回合平均长度只报。`-ot3-` run 的 chord_sr 与失败原因比例按 0.3 m 算，与变体 A 不可比（t2term 第 3 节）。
- 导出那一局不在这一轮做；不按榜上分数挑东西。这一轮不提交。

## 3. 风险

- 续训从空 replay 开始，前 409600 步只收集不更新，之后 critic 先用新分布的数据，奖励归一化的折扣回报清零，可能有一小段不稳；两个分支都受影响，K0 把这部分单独读出来。发散看守照常。
- F 全部从第 0 帧起跑，回合一终止就回到第 0 帧，参考后段（ep25 第 300 帧以后）只有活得够久的回合才见得到，可能把后段忘掉，F3 管这种情况。
- 起点是 mf4090 的 ot3 run，不是现在交的那条；F 好过起点，不等于好过清单里的那条。
- 只有一个种子。
- mf4090 被占约 2.5 小时。
